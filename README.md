# ooas-spec

Open Operator Attestation Standard: a signed, expiring, revocable format for Solana validator operators to state the operational and security controls they run, verifiable by anyone.

Draft. See [SCHEMA.md](SCHEMA.md). Prior art, including the Operator Register, is in section 9.

Related: on-chain registry at [permissioned-token](https://github.com/Digitalenergyllc/permissioned-token).
